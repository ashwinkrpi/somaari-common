# somaari-common (Python)

Python adapters for [somaari-common](https://github.com/ashwinkrpi/somaari-common):

- `somaari_about`: the About section data and debug-info collector. See `docs/ABOUT_SPEC.md` in that repo.
- `somaari_theme`: the shared themes (`theme.js`, `themes.css`, fonts) for Python web apps to serve at `/theme/`. See `docs/THEME_SPEC.md`.
